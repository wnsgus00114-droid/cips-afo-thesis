# 3D Models (GitHub Interactive)

아래 파일은 GitHub 파일 뷰어에서 마우스로 회전/확대/축소가 가능하다.

## 1) A.F.O 3D Chip Package
- [afo_chip_package_3d.obj](./afo_chip_package_3d.obj)
- [afo_chip_package_3d.stl](./afo_chip_package_3d.stl)
- [afo_chip_package_3d.mtl](./afo_chip_package_3d.mtl)

모델 구성:
1. substrate
2. compute die
3. silicon bridge slab
4. CPU/GPU/NPU/SRAM zones
5. Layer-2 inner HBM rectangular ring (full compute surround)
6. Layer-2 outer HBF rectangular ring (full HBM surround)

## 2) A.F.O Full Hardware System

- [afo_hardware_system_3d.mtl](./afo_hardware_system_3d.mtl)

모델 구성:
1. main board
2. chip socket/package
3. heatsink + fan

5. CXL/PCIe slots
6. host memory modules
7. power block
